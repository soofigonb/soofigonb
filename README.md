## 🌷 Proyectos destacados

### 🥑 NutriVida

Aplicación web para una clínica nutricional enfocada en facilitar el acceso a sus profesionales y servicios.

Incluye funcionalidades como visualización de nutricionistas, planes nutricionales, agendamiento de citas y gestión de usuarios.

**୨୧ Tecnologías utilizadas**

`React` · `JavaScript` · `HTML` · `CSS` · `Bootstrap`

♡ [**Ver proyecto NutriVida**](https://github.com/soofigonb/nutrivida-react)

<br>

### 🐾 Hostly Pets

Plataforma para la gestión de **alojamientos pet friendly**, desarrollada utilizando una arquitectura basada en microservicios.

El sistema cuenta con servicios independientes para la gestión de usuarios, propiedades, reservas y pagos, comunicados mediante **API Gateway** y **Eureka**.

**୨୧ Tecnologías utilizadas**

`Java` · `Spring Boot` · `Spring Cloud` · `PostgreSQL` · `REST API`

♡ [**Ver proyecto Hostly Pets**](https://github.com/soofigonb/Hostly_Pets)
